# Python3 基础语法

> Python3 学习笔记 · 整理自菜鸟教程

## 一句话
Python 用缩进组织代码块，标识符区分大小写，语句结尾一般不加分号，语法简洁直观。

## 要点
- **缩进**：用缩进表示代码块，同一块内缩进必须一致，官方推荐 4 个空格。
- **标识符**：由字母、数字、下划线组成，不能以数字开头，区分大小写。
- **保留字**：`if`、`for`、`class`、`def`、`return` 等不能作变量名，用 `keyword.kwlist` 查看。
- **行与续行**：一行为一条语句；长语句可用反斜杠 `\` 换行，或放在括号内自动续行。
- **多语句同行**：可用分号 `;` 分隔，但不推荐。
- **注释**：单行 `#`，多行用三个引号。
- **输入输出**：`input()` 读入字符串，`print()` 输出。
- **代码块**：冒号 `:` 引出缩进块，常见于 if、for、def、class。

## 语法 / 常用方法

| 语法/方法 | 说明 | 示例 |
|---|---|---|
| `# 注释` | 单行注释 | `# 说明文字` |
| `"""..."""` | 多行字符串/文档串 | `"""多行内容"""` |
| `\` 续行 | 一条语句跨多行 | `total = 1 + \` |
| `( )` 续行 | 括号内自动换行 | `x = (1 + 2 + 3)` |
| `;` | 一行写多条语句 | `a = 1; b = 2` |
| `input()` | 读取用户输入（字符串） | `name = input("名字: ")` |
| `print()` | 输出 | `print("hi", 1, sep="-")` |
| `import keyword` | 查看保留字 | `print(keyword.kwlist)` |

## 代码示例

```python
import keyword

# 缩进决定代码块，下面是 4 个空格
if True:
    print("进入 if 块")
    print("同一缩进属于同一块")
print("回到外层")

# 标识符：区分大小写
name = "Alice"
Name = "Bob"
print(name, Name)          # 两个不同的变量

# 查看 Python 保留字
print("保留字:", keyword.kwlist)

# 长语句用反斜杠续行
total = 1 + 2 + 3 + \
        4 + 5
print("total =", total)

# 括号内可自由换行，更推荐
numbers = [
    1, 2, 3,
    4, 5,
]
print("numbers =", numbers)

# 一行写多条语句（不推荐）
a = 1; b = 2
print(a + b)

# 输入输出
# name = input("请输入姓名: ")   # 交互式示例
# print("你好,", name)

# print 常用参数
print("a", "b", "c", sep="-")      # a-b-c
print("不换行", end=" ")
print("继续")
```

## 易错点
- **Tab 与空格混用**：会报 `TabError`，整个项目统一用空格。
- **漏写冒号**：`if x > 0` 后面少了 `:` 会报 `SyntaxError`。
- **`input()` 返回字符串**：要参与数值运算必须先 `int()`/`float()` 转换。
- **单行 if 也要缩进**：`if True: print("x")` 可以，但冒号后的块仍需保持缩进规范。
- **保留字当变量名**：如把变量命名为 `class`、`for`，会直接语法错误。
- **中文标识符**：Python3 允许，但工程中不推荐，易踩编码坑。
